This repo contains materials I created for educational purposes. 

It includes some of the original work I developed for the third-year undergraduate subject **PHYC30021 - Laboratory and Computational Physics 3** at The University of Melbourne:
1. A Bayesian inference and gravitational-wave themed computational activity (GW_CBC_LabNotes.pdf)
2. An “Introduction to Python Programming" guide (ThirdYearIntro.pdf)
While the materials shared here are incomplete, we are very happy to share the materials used in this subject. If you are interested in using any of these materials and/or would like to learn more about other materials available in this subject, please get in touch (email - christine.yishuen@unimelb.edu.au).

It also includes some of the materials I developed for educational workshops/seminars:
